# 璀璨宝石 · 在线多人版

和朋友们在手机浏览器里开一局 Splendor。房间码 + 邀请链接,点开即玩,无需安装。

## 玩法

1. 房主创建房间(可选模块:城市 / 贸易站),把邀请链接或 4 位房码发给朋友(2-4 人)
2. 人不够?房主可在房间内「添加机器人陪玩」,机器人自动行动,一个人也能开局测试
3. 房主点「开始游戏」
4. 手机锁屏 / 切后台掉线后重新打开,会自动回到对局

## 本机运行

```bash
npm install
npm start          # 默认 3000 端口,PORT 环境变量可改
```

同一局域网内手机访问 `http://<电脑IP>:3000` 即可试玩。

## 部署(Zeabur / ClawCloud 等)

单进程 Node 服务,HTTP 与 WebSocket 同端口,已提供 Dockerfile:

- 端口:平台注入 `PORT` 环境变量(本地默认 8080)
- 健康检查:`GET /healthz`
- 若平台通过可信反向代理转发流量,设置 `TRUST_PROXY=1`,使连接与建房限流按真实客户端 IP 生效;不要在可绕过代理直连的部署中开启
- **务必单实例部署**(状态在内存中,多副本会导致玩家散落在不同进程);进程重启则对局丢失,适合朋友局

## 测试

```bash
npm test           # 规则单测 + 数据校验 + 随机 bot 模拟(含扩展开) + WS 集成测试
```

## 规则实现说明

- 基础版:官方规则(贵族张数 = 人数+1;平局比发展卡数;预留上限 3 张;预留拿金也可能触发超 10 弃置等)
- 扩展按 **Silk Road(2024)官方规则** 实现:
  - **城市**:3 张城市卡取代贵族,15 分终局关闭;回合末检查「声望达标 + 卡色达标」,有人达成后轮完本轮,同轮多人达成比声望分,再比卡数
  - **贸易站**:5 项特权,回合末(贵族之后)自动授予,每回合限 1 项;效果含买牌拿宝石 / 同色拿2附赠1 / 金当2同色 / 盲抽看二留一 / 每特权 1 分
- 买牌支付为服务端自动求解(优先用本色宝石,最少动用金币);持「铸金行会」时每枚金币可抵某单色 2 颗,超出不找零
- 卡牌数据(90 发展卡 / 10 贵族)来自两个独立开源实现交叉核对;城市卡 3 张为官方确认数值,另 3 张按官方模式配置(见 `data/cards.json`,`official` 字段),可随时替换
- 微信内打开:平台分配的域名在微信内置浏览器可能被拦截,建议用系统浏览器打开或直接部署在已备案域名上

## 目录结构

```
server.js          HTTP 静态 + WS + 房间/会话/清理
game/engine.js     规则引擎(纯函数,零 IO,可复用到小程序)
data/cards.json    全部卡牌/贵族/城市/贸易站数据
public/            零构建单页前端(大厅/房间/对局三屏)
test/              引擎单测 + bot 模拟 + 服务端集成测试
```

## 已知限制

- 内存态无数据库:重启丢局、无断线代打(掉线玩家回合会等待)
- 无观战、无回合回放、无单机 AI
- 对局中"退出"为离线挂起(座位保留,可从链接回来);只有房主能作废本局或解散房间
